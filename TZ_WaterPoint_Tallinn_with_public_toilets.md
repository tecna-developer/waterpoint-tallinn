## 1. Основание и исходные данные

Документ собран из текущего чата: идея мобильного приложения без кода / с возможностью разработки, которое показывает ближайший общественный кран питьевой воды Tallinna Vesi в Таллине. В чате были зафиксированы пожелания: рассмотреть оба варианта реализации, включить все предложенные функции, выдержать экологичный и водный визуальный стиль, рабочее название может быть временно предложено исполнителем.

Внешняя ссылка на общий чат ChatGPT была проверена, но открылась только как страница входа без содержимого переписки. Поэтому детали из ссылки не были извлечены; документ основан на доступной истории этой беседы и открытых источниках.

Открытые источники Tallinna Vesi и Visit Tallinn подтверждают, что общественные краны питьевой воды работают сезонно, имеют QR-коды с картой точек, в 2026 году в Таллине открыто 75 точек, а всего с Saue и Maardu — 78. Tallinna Vesi также заявляет, что вода контролируется и подходит для питья.

## 2. Краткая концепция

VeeLähedal — мобильное приложение, которое помогает жителям и гостям Таллина быстро найти ближайший общественный кран питьевой воды, построить маршрут и понять, открыт ли он сейчас. Дополнительно приложение показывает на карте общественные туалеты как отдельный слой городской инфраструктуры, чтобы пользователь мог решить две частые задачи во время прогулки: где набрать воду и где найти ближайший туалет.

### 2.1. Цели продукта

- Сократить время поиска ближайшего питьевого крана в городе.

- Показать пользователю только релевантные и доступные точки с учетом сезона, расстояния и особенностей точки.

- Сделать интерфейс простым для жителей, туристов, семей с детьми, велосипедистов, бегунов и владельцев собак.

- Дополнить карту полезным городским слоем: ближайшие общественные туалеты с маршрутом, статусом, условиями доступа и источником данных.

- Поддержать экологичное поведение: refill вместо покупки воды в пластике.

- Собрать MVP так, чтобы его можно было сначала проверить no-code способом, а затем при необходимости перенести в полноценную разработку.

### 2.2. Не является на старте

- Официальным приложением Tallinna Vesi без отдельного согласования с компанией.

- Сервисом гарантии качества воды в реальном времени: качество воды подтверждается источником данных, но приложение не измеряет его самостоятельно.

- Сервисом экстренной помощи или критической инфраструктуры.

## 3. Целевая аудитория и сценарии

| **Аудитория** | **Потребность** | **Основной сценарий** |
| --- | --- | --- |
| Жители Таллина | Быстро наполнить бутылку во время прогулки | Открывает приложение → видит ближайший кран → строит пеший маршрут |
| Туристы | Найти бесплатную питьевую воду без знания города | Открывает карту → выбирает ближайшую точку рядом с достопримечательностью |
| Родители с детьми | Понять, где можно набрать воду на площадке или в парке | Фильтр “рядом с парком/площадкой” или просмотр точек на карте |

## 4. Объем MVP

MVP должен отвечать на один главный вопрос пользователя: “Где ближайшая питьевая вода и как туда дойти?”

### 4.1. Входит в MVP

- Карта общественных кранов Tallinna Vesi.

- Определение геолокации пользователя с явным разрешением.

- Автоматический показ ближайшей точки.

- Список точек, отсортированный по расстоянию.

- Карточка точки: название/адрес или ориентир, расстояние, статус, сезонность, признаки “на улице/в помещении”, “есть миска для собак”, ссылка на маршрут.

- Построение маршрута через внешние карты: Google Maps, Apple Maps или встроенный провайдер.

- Языки интерфейса: русский и эстонский как минимум; английский желательно для туристов.

- Форма “сообщить о проблеме”: кран не работает, нет воды, повреждение, неверная локация.

- Экологичный экран/блок: мотивация использовать многоразовую бутылку.

- Построение маршрута до общественного туалета через те же внешние карты, что и для кранов.

- Карточка общественного туалета: название/ориентир, адрес, часы работы, платность, доступность, источник и дата проверки.

- Фильтр по типу точки: “Вода”, “Туалеты”, “Все”.

- Отдельный слой “Общественные туалеты” на карте: включение/выключение слоя, отдельная иконка и карточка точки.

### 4.2. Не входит в первый MVP, но можно запланировать

- Личный аккаунт пользователя.

- Геймификация, достижения, счетчик сэкономленных бутылок по пользователю.

- Онлайн-статус занятости туалета в реальном времени.

- Офлайн-карты.

- Push-уведомления о новых точках или сезонном открытии.

- Сложная админ-панель с ролями и модерацией.

- Интеграция с официальной API Tallinna Vesi, если такой доступ не согласован.

## 6. Данные

### 6.1. Источник данных

Базовые источники для MVP — публичная карта/страницы Tallinna Vesi и Tallinn GIS с общественными питьевыми кранами, а также публичные городские источники по общественным туалетам, например Visit Tallinn. Перед публикацией продукта нужно проверить условия использования данных, частоту обновления, разрешение на отображение точек и корректное указание источников.

### 6.2. Структура записи точки

| **Поле** | **Тип** | **Описание** | **Обязательность** |
| --- | --- | --- | --- |
| id | string | Уникальный ID точки | Да |
| name | string | Название или краткий ориентир | Да |
| address | string | Адрес или описание места | Желательно |
| latitude | decimal | Широта | Да |
| longitude | decimal | Долгота | Да |
| district | string | Район Таллина | Желательно |
| type | enum | outdoor / indoor / event / unknown | Да |
| season_start | date/month | Ориентировочное начало сезона | Для outdoor |
| season_end | date/month | Ориентировочное окончание сезона | Для outdoor |
| status | enum | active / inactive / seasonal / unknown / reported_problem | Да |
| dog_bowl | boolean | Есть ли миска для собак | Желательно |
| source_url | url | Ссылка на источник | Да |
| last_verified_at | datetime | Дата последней проверки данных | Да |
| notes | text | Комментарии администратора | Нет |
| category | enum | water_tap / public_toilet. Нужен для фильтрации, иконок и разных карточек. | Да |
| opening_hours | text/json | Часы работы. Для кранов может быть сезонность; для туалетов - часы/режим доступа. | Для туалетов желательно |
| is_free | boolean/unknown | Бесплатный ли туалет. Если данных нет, показывать “неизвестно”, а не угадывать. | Для туалетов желательно |
| accessibility | enum/text | Информация о доступности: wheelchair_accessible / limited / unknown, если источник это подтверждает. | Желательно |
| baby_changing | boolean/unknown | Есть ли пеленальный столик, если источник это подтверждает. | Опционально |
| operator | string | Кто отвечает за точку: город, частный оператор, Tallinna Vesi и т.д. | Желательно |

### 6.3. Особенности данных для общественных туалетов

- Туалеты должны храниться в той же базе точек, что и краны, но отличаться полем category = public_toilet.

- Если часы работы, платность или доступность неизвестны, интерфейс должен честно показывать “нет данных”, а не скрывать поле полностью.

- Для туалетов важно отдельно проверять источник, дату последней проверки, возможную сезонность и ограничения доступа.

- В жалобах пользователей для туалетов нужны отдельные типы проблем: закрыто, грязно/повреждено, неверные часы, неверная локация, больше не существует.

### 6.4. Обновление данных

- На MVP-этапе: ручное обновление таблицы 1 раз в неделю в сезон и 1 раз в месяц вне сезона.

- Перед началом сезона: сверка всех точек по официальной карте.

- После жалобы пользователя: помечать точку как “reported_problem” до проверки.

- Для полноценной версии: автоматическая синхронизация, если будет доступна официальная API или стабильный экспорт данных.

## 7. UX/UI требования

Стиль: экологичный, чистый, водный. Визуальное настроение — свежесть, доверие, простота, городская навигация. Цветовая основа: оттенки воды, светлый фон, зеленые экологичные акценты. Иконки — простые, дружелюбные, без перегруза.

### 7.1. Основные экраны

| **Экран** | **Содержимое** | **Ключевое действие** |
| --- | --- | --- |
| Onboarding | 1–2 экрана: зачем приложение, разрешение геолокации, выбор языка | Разрешить геолокацию / пропустить |
| Карта | Карта, текущая позиция, маркеры кранов и общественных туалетов, переключатель слоев, кнопка ближайшей точки | Найти ближайший кран или туалет |
| Список | Точки по расстоянию, фильтры, поиск, переключатель типа точки: вода / туалеты / все | Открыть карточку точки |
| Карточка точки | Описание, статус, расстояние, особенности, маршрут, источник. Для туалета: часы работы, платность, доступность, дата проверки. | Построить маршрут |
| Сообщить о проблеме | Тип проблемы, комментарий, фото опционально | Отправить |
| О проекте | Экологичная миссия, источники данных, дисклеймер | Узнать источник данных |
| Слой туалетов | Переключатель слоя, отдельные иконки, легенда карты | Показать/скрыть туалеты |
| Карточка туалета | Адрес, часы, платность, доступность, источник, дата проверки, жалоба | Построить маршрут |

### 7.2. Тексты и микрокопи

- Пример главной кнопки: “Найти воду рядом”.

- Сообщение о геолокации: “Разрешите доступ к местоположению, чтобы мы нашли ближайший кран. Мы не сохраняем вашу геолокацию без необходимости.”

- Вне сезона: “Наружные краны обычно работают в теплый сезон. Проверьте статус перед маршрутом.”

- Экологичный текст: “Наполните бутылку повторно — меньше пластика, больше чистой воды в городе.”

- Если по туалету неизвестны часы работы или платность: “Нет подтвержденных данных. Проверьте на месте.”

- Пример подписи слоя: “Показать туалеты”.

- Легенда карты должна ясно различать “Вода” и “Туалеты”: разные иконки, подписи и фильтр.

## 8. Нефункциональные требования

| **Категория** | **Требование** |
| --- | --- |

## 9. Варианты реализации

### 9.1. Вариант A — no-code / low-code MVP

Цель: быстро проверить идею без полноценной разработки.

| **Компонент** | **Рекомендация** |
| --- | --- |
| Платформа | FlutterFlow, Glide, Softr или Adalo. Для карты и мобильного UX предпочтительнее FlutterFlow; для максимально быстрого прототипа — Glide. |
| База данных | Google Sheets / Airtable / Supabase. Для начала проще Airtable или Google Sheets; таблица должна поддерживать category для кранов и туалетов. |
| Карты | Google Maps, Mapbox или встроенный компонент выбранной платформы. |
| Форма жалоб | Встроенная форма → таблица/база администратора. |
| Публикация | PWA для теста; затем Android/iOS, если платформа и бюджет позволяют. |

Плюсы: быстро, дешевле, удобно проверять гипотезу. Минусы: ограничения по кастомизации карты, производительности, офлайн-режиму и сложной логике.

### 9.2. Вариант B — полноценная разработка

Цель: стабильное приложение с хорошим UX, масштабированием и возможностью развивать функции.

| **Слой** | **Рекомендация** |
| --- | --- |
| Мобильное приложение | Flutter или React Native. Flutter подойдет для единого аккуратного UI и быстрой кроссплатформенной разработки. |
| Backend | Node.js/NestJS, Python/FastAPI или Supabase как backend-as-a-service. |
| База данных | PostgreSQL + PostGIS для геоданных. Единая таблица POI с category = water_tap/public_toilet или отдельные таблицы с общим API. |
| Карты | Mapbox / Google Maps / Apple Maps links. |
| Админка | Простая web-админка для точек, статусов, жалоб, источников данных и отдельных типов объектов: краны и общественные туалеты. |
| Аналитика | Privacy-friendly аналитика: события без точной истории перемещений. |

Плюсы: гибкость, надежность, контроль над данными и UX. Минусы: дороже и дольше, нужен разработчик или команда.

| Этап 3: Пользовательская обратная связь | Форма жалоб по кранам и туалетам, статусы, админская таблица | Можно поддерживать актуальность данных |
| Этап 4: Публичный запуск | Мультиязычность, polish UI, юридические тексты, публикация | PWA или app-store-ready версия |
| Этап 5: Развитие | Геймификация, избранное, офлайн, партнерство с Tallinna Vesi | Продуктовая версия |
| Этап 2a: Слой туалетов | Добавить отдельные маркеры, фильтр, карточку туалета, маршрут и источник данных | Пользователь может найти не только воду, но и ближайший общественный туалет |

## 11. Критерии приемки MVP

- При первом запуске пользователь понимает, зачем приложению геолокация.

- После разрешения геолокации приложение показывает ближайший кран и расстояние до него.

- Все точки отображаются на карте и в списке.

- Карточка точки открывается из карты и списка.

- Кнопка маршрута открывает внешний картографический сервис с выбранной точкой.

- Пользователь может отправить сообщение о проблеме по конкретной точке.

- В интерфейсе есть предупреждение о сезонности наружных кранов.

- Данные имеют источник и дату последней проверки.

- Приложение не сохраняет точную геолокацию пользователя без явного согласия.

- Тексты доступны минимум на русском и эстонском.

- Если данные о часах работы, платности или доступности туалета неизвестны, приложение показывает “нет данных”, а не выдает непроверенную информацию.

- Карточка туалета показывает минимум адрес/ориентир, источник данных, дату проверки и маршрут.

- Фильтр “Вода / Туалеты / Все” корректно меняет карту и список.

- Пользователь может включить слой общественных туалетов на карте.

## 12. Риски и открытые вопросы

| **Риск/вопрос** | **Почему важно** | **Что сделать** |
| --- | --- | --- |
| Право на использование данных и бренда | Нельзя выдавать приложение за официальное без разрешения | Связаться с Tallinna Vesi / городом Таллинном, уточнить условия |
| Актуальность статусов | Пользователь может прийти к закрытому или неработающему крану | Показывать дату проверки, сезонность и форму жалобы |
| Сезонная работа наружных точек | Вне сезона часть кранов закрывается | Добавить сезонное предупреждение и фильтр “актуально сейчас” |
| Точность геолокации | В городе GPS может ошибаться | Давать адрес/ориентир, не только точку на карте |
| No-code ограничения | Карты и фильтры могут работать не так гибко | Сначала сделать простой PWA, затем решить, нужен ли custom |
| Мультиязычность | Приложением могут пользоваться туристы | Сразу заложить структуру переводов RU/ET/EN |
| Данные по общественным туалетам могут быть неполными | Пользователь может прийти к закрытому объекту или ожидать бесплатный доступ | Показывать источник, дату проверки, “нет данных”, форму жалобы и не обещать доступность без подтверждения |
| Смешение кранов и туалетов на карте | Пользователь может не понять, что за точка перед ним | Использовать разные иконки, легенду, фильтр и разные карточки для water_tap/public_toilet |
| Платность и часы работы туалетов | Эти параметры могут меняться чаще, чем координаты | Хранить opening_hours/is_free отдельно, регулярно перепроверять и показывать дату обновления |
