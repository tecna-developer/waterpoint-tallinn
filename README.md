# WaterPoint Tallinn

PWA-прототип приложения для поиска общественных питьевых кранов **и общественных
туалетов** в Таллине. Дизайн — по макетам Stitch «WaterPoint Tallinn» (светлая тема),
функциональность — по ТЗ «VeeLähedal» v0.1 ([`TZ_WaterPoint_Tallinn_with_public_toilets.md`](TZ_WaterPoint_Tallinn_with_public_toilets.md)).

**🔗 Демо:** https://tecna-developer.github.io/waterpoint-tallinn/

Карта и список **174 реальных точек** (78 питьевых кранов + 96 общественных туалетов)
из Tallinn GIS, переключатель «Вода / Туалеты / Все», поиск по адресу и району,
фильтры, карточка с маршрутом во внешние карты, локальное избранное, сообщение о
проблеме, интерфейс ET/EN/RU, светлая и тёмная темы. Работает как устанавливаемое PWA
с офлайн-кешем списка точек.

## Установка на телефон (PWA)

Откройте демо-ссылку и добавьте на главный экран:
- **Android (Chrome):** меню ⋮ → «Добавить на главный экран».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

После установки приложение открывается без адресной строки; список и карточки
точек доступны офлайн (карта-подложка требует сети).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

Деплой на GitHub Pages — автоматически при пуше в `main`
(workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)).

| FR-02 Ближайшая точка | Must | ✅ расчёт по гаверсинусу, сортировка по расстоянию, время пешком |
| FR-03 Карта | Must | ✅ маркеры различают **тип точки формой** (капля / пин WC) и доступность цветом **и** глифом статуса |
| FR-04 Список | Must | ✅ тот же набор результатов, что на карте, сортировка по расстоянию |
| FR-05 Карточка точки | Must | ✅ адрес/ориентир, район и асум, расстояние, статус, сезонность, особенности, источник, дата проверки, мини-карта, маршрут |
| FR-06 Маршрут | Must | ✅ deep link во внешние карты (Apple Maps на iOS/iPadOS, иначе Google Maps), пешком по умолчанию |
| FR-07 Поиск | Should | ✅ районы (linnaosa), названия точек, онлайн-геокодинг Nominatim (ограничен Таллином) |
| FR-08 Фильтры | Should | ⚠️ «открыто сейчас», радиус ≤1/2/5 км, избранное. Чипы «с миской для собак» и indoor/outdoor **скрыты**: источник таких признаков не даёт, показывать пустой фильтр нечестно |
| FR-09 Сообщить о проблеме | Should | ⚠️ форма с категориями, комментарием, контактом, согласием, honeypot и rate-limit. Отчёты пишутся в localStorage — приёмника на сервере нет (нужен backend) |
| FR-10 Сезонность | Must | ✅ баннер «наружные краны работают в тёплый сезон» вне мая–октября + статус `seasonal_closed` |
| FR-11 Многоязычность | Should | ✅ RU/ET/EN, автовыбор по языку устройства, ручной — в онбординге и настройках |
| FR-12 Экологичный блок | Could | ✅ в настройках и в карточке крана |
| FR-13 QR / поделиться | Could | ⚠️ «Поделиться точкой» через `navigator.share` с фолбэком на копирование ссылки и deep link `?p=<id>`. QR-код не генерируется |
| FR-14 Слой общественных туалетов | Should | ✅ отдельные маркеры, легенда карты, включение/выключение слоя |
| FR-15 Карточка туалета | Should | ✅ адрес, тип (стационарный / временный со сроком), часы, платность, доступность, источник, дата проверки, маршрут, жалоба |
| FR-16 Фильтр по типу точки | Must | ✅ «Вода / Туалеты / Все» согласованно меняет карту и список; иконки и подписи типов не смешиваются |
| FR-17 Жалоба по туалету | Could | ✅ свой набор проблем: закрыто, грязно/повреждено, неверные часы, неверная локация, больше не существует |

Дополнительно: приватная аналитика (события `app_open` / `search` / `point_open` /
`route_start` / `report_submit` / `share_point` в localStorage, без геолокации),
избранное и офлайн-кеш, светлая и тёмная темы.

Статусы точек: `available`, `seasonal_closed` (только краны, вне мая–октября),
`reported_issue` (предупреждение до модерации, официальный статус не меняется),
`temporarily_unavailable`, `unknown`.

## Данные

Оба слоя живут в одной модели точки и различаются полем `category`
(`water_tap` / `public_toilet`), как требует §6.2 ТЗ.

| Слой | Источник | Точек |
|------|----------|-------|
| Питьевые краны | Tallinn GIS ArcGIS REST, `veebikaart/Veev6tukohad` («Avalikud veevõtukohad») | 78 |
| Общественные туалеты | Tallinn GIS ArcGIS REST, `veebikaart/avalikud_tualetid` (слой 0) | 96 |

- Слои синхронизируются независимо: недоступность одного не стирает последнюю
  успешную копию другого. Снапшоты для офлайна и первого запуска —
  `src/data/waterpoints.json` и `src/data/toilets.json`.
- Районы (linnaosa) и асумы вычислены point-in-polygon по слою `Linnaosad_asumid`.
- Туалеты: 27 стационарных и 69 временных. У временных источник даёт дату демонтажа —
  она показывается в карточке, а после её наступления точка исчезает из выдачи.
  10 записей слоя не имеют геометрии и отбрасываются.
- **Часов работы, платности и доступности туалетов в источнике нет.** Интерфейс
  честно показывает «нет данных» и подсказку «проверьте на месте» (§6.3), а не
  выдумывает значения.
- Фото точек в источнике нет — используются нейтральные заглушки по категориям.
- Обновление снапшота туалетов (§6.4, ручное):
  ```bash
  node scripts/gen-toilets.mjs src/data/toilets.json
  ```
- Перед релизом подтвердить условия повторного использования данных обоих слоёв.

## Приватность

Точная геолокация не сохраняется и никуда не отправляется; избранное, кеш и отчёты —
только на устройстве.
